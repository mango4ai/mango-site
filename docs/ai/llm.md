# 三、大模型 LLM

从这一页开始，就进入现在大家真正在用的东西了。先说清楚一件事：**LLM 并没有一个"知识库"让你查询，它做的事情从头到尾只有一件——预测下一个 token。**

## LLM 是什么

**LLM（Large Language Model，大语言模型）**：在海量文本上训练出来的超大神经网络，**核心任务是"根据前文预测下一个 token"**；因为训练数据足够多、规模足够大，它在练这项技能的过程中顺带学会了语法、世界知识、推理、写作、改写和总结。

一句话定义：**LLM 是一个把"接话"练到极致的机器。**

理解这个定义，能一次性解释它的几乎所有行为：

| 现象 | 用"接话机器"怎么解释 |
| --- | --- |
| 写诗写代码都行 | 训练语料里这些文本都有，它学会了各自的套路 |
| 会一本正经地编造事实 | 它优化的是"接得通顺"，不是"说得正确" |
| 换个问法答案就变 | 前文变了，预测就变了 |
| 让它一步步想，正确率变高 | 它生成的"思考过程"成了自己后续预测的前文 |

## 它是怎么被造出来的

一个可用的大模型通常经历三个阶段：

1. **预训练（Pre-training）**
   在海量文本（网页、书籍、代码等）上做一件事：遮住下一个 token，让它猜，猜错就调参数。
   → 这一步最烧钱（几千张 GPU 跑几个月），产出的是一个"什么都知道一点、但不会好好说话、也不知道该拒绝什么"的**基座模型**。

2. **后训练 / 对齐（Post-training / Alignment）**
   让模型从"接话机器"变成"有用的助手"：
   - **SFT（监督微调）**：人工写一批高质量的"提问—回答"示范，让模型模仿。
   - **RLHF / 偏好优化**：让模型生成多个答案，人类（或另一个模型）挑出更好的，据此调整——**把"人类更喜欢哪种回答"教给模型**。
   → 我们平时对话用的 ChatGPT 类产品，都是对齐后的模型。

3. **推理（Inference）**
   参数固定，对外提供服务。我们调 API 就是这一步。

> **"大模型"到底大在哪**：主要是**参数量**（旋钮数量，从亿级到千亿级）和**训练数据量**。规模上去之后会涌现出小模型没有的能力（比如少样本学习、链式推理），这被称为**涌现能力**——但它不是魔法，只是量变堆出的质变。

## 用的时候要懂的几个概念

### 提示词（Prompt）

**提示词就是你喂给模型的全部前文。** 它不是一个玄学咒语，而是你唯一能控制模型行为的旋钮。

几个立刻见效的原则：

- **说清楚角色、目标、约束、输出格式**，别指望它猜。
- **给例子**（少样本提示）比反复描述要求更有效。
- **把复杂任务拆成步骤**，让它一步步来（思维链）。
- **让它先说依据再下结论**，能显著降低胡编率。
- 不确定时，要求它**给出来源，或明确说"不确定"**。

### 上下文窗口

**上下文窗口 = 模型一次能看到的 token 上限**，包含你的提示、它之前的回答、你贴进去的文档。

- 超长对话会被截断或压缩，表现为"它忘了前面说过什么"。
- 窗口大 ≠ 都能用好。塞太多无关内容反而会稀释重点（"大海捞针"问题）。
- **每次 API 调用都是无状态的**——之所以看起来记得，是因为程序把历史对话又重新发了一遍。

### 温度（Temperature）

- **低温度（0～0.3）**：几乎总是选概率最高的词 → 稳定、可复现，适合写代码、抽取数据。
- **高温度（0.8+）**：更容易选到低概率词 → 更有创意，也更容易出错。

### 幻觉（Hallucination）

**模型生成了看似合理但事实上错误的内容。** 这不是 bug，是它的工作原理决定的。

实用的应对办法：

- 让它**只依据你给的 material 回答**，并注明"材料里没提到就说不知道"。
- 涉及事实、数字、法条、人名，**一律二次核实**。
- 开启联网搜索或接检索（见 [发散：RAG](/ai/beyond)），让它有据可依。
- 让它**自己检查一遍**（"复查上面的回答，指出可能错误的地方"）确实有用。

## 怎么用上它

对普通人到开发者，门槛是递进的：

1. **直接用产品**：网页 / App 对话，零门槛。
2. **调 API**：把模型接进自己的程序里，按 token 付费。
3. **在本地跑**：用开源模型（参数较小）跑在自己的机器上，隐私好、不花钱，但能力弱一档。
4. **在上面搭应用**：检索、工具调用、多步流程——这就进入下一页的 [Agent](/ai/agent) 了。

## 它做不到什么

- **不知道训练截止之后的事**（所以需要联网 / 检索）。
- **不会真的"记住你"**，除非应用层把记忆存下来再喂给它。
- **不会自己验证事实**，除非你给它工具让它去查。
- **不擅长精确计算**：让它算大数乘法，不如让它写一段代码去算。
