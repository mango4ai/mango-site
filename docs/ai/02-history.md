# AI 发展简史

AI 不是 2022 年突然冒出来的。它已经折腾了七十年，中间冷过两次。看懂这些起伏，比追新模型名字有用得多。

## 起点：先有想法（1943 — 1956）

| 年份 | 事件 | 意义 |
| --- | --- | --- |
| 1943 | McCulloch 与 Pitts 提出神经元数学模型 | 第一次用数学描述"神经元怎么计算" |
| 1950 | 图灵发表《计算机器与智能》，提出图灵测试 | 把"机器能否思考"换成可操作的判断 |
| 1956 | 达特茅斯会议，McCarthy 定名 "Artificial Intelligence" | 这个学科正式有了名字 |

## 第一次热潮与寒冬（1957 — 1980）

早期主流是**符号主义**：把知识写成规则和逻辑，让机器推理。这一时期成果不少——能解代数题、能证明定理、1966 年的 ELIZA 甚至能模仿心理医生对话。

但问题也很快暴露：规则靠人工写，遇到真实世界的模糊问题就崩。1969 年 Minsky 与 Papert 指出单层感知机连"异或"都学不会，加上算力根本撑不住，1974 年前后 funding 大幅收缩，**第一次 AI 寒冬**到来。

## 专家系统与第二次寒冬（1980 — 1993）

1980 年代靠"专家系统"回了一波血：把人类专家的经验写成规则库，XCON 帮 DEC 配置计算机订单，一度年省数千万美元。商业化热闹起来。

结局也相似：规则库维护成本爆炸、无法泛化、专用硬件市场被通用工作站冲垮，1987 年后再度崩盘，**第二次寒冬**。

## 悄然翻身：统计学习与算力（1993 — 2011）

- 1997 年，深蓝击败卡斯帕罗夫——靠的是暴力搜索，不是学习。
- 2000 年代，统计机器学习（SVM、随机森林）成为实用主力，互联网带来了数据。
- 2006 年，Hinton 等人提出深度信念网络的有效训练方法，"深度学习"这个名字重新被提起。
- 2009 年，李飞飞团队发布 ImageNet——**数据**这块拼图到位了。

## 深度学习爆发（2012 — 2017）

- 2012 AlexNet 在 ImageNet 上大幅领先，GPU 训练 + 深层 CNN 的组合被验证。
- 2014 GAN 出现，生成式模型第一次真正可用。
- 2016 AlphaGo 击败李世石，强化学习出圈。
- **2017 Google 发表《Attention Is All You Need》，提出 Transformer。** 这是今天一切大模型的技术地基。

## 大模型时代（2018 — 至今）

| 年份 | 事件 |
| --- | --- |
| 2018 | GPT-1、BERT：预训练 + 微调成为范式 |
| 2019 | GPT-2（15 亿参数），因"太会编"一度被谨慎发布 |
| 2020 | GPT-3（1750 亿参数），少样本学习显现，提示词开始重要 |
| 2022 | ChatGPT 发布，两个月破亿用户，AI 真正进入公众视野 |
| 2023 | GPT-4、开源模型 Llama 系列，人人都能跑本地模型 |
| 2024 | 多模态成为标配；Anthropic 开源 MCP 协议；推理模型出现 |
| 2025 起 | Agent 与工具生态成为主战场，模型开始"动手干活" |

## 三条规律

1. **每次高潮都源于算力、数据、算法三者同时到位**，缺一个就只能停留在论文里。
2. **每次寒冬都是因为"演示很惊艳，落到真实场景就散架"**。今天对 Agent 的质疑也是同一句话。
3. **范式转移比参数增长更关键**：规则 → 统计 → 深度学习 → 预训练大模型 → Agent，每一次都是换打法，不只是堆料。
