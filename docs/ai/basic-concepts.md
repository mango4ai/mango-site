# 1. 入门概念：人工智能、机器学习、深度学习

刚接触 AI 时最容易被一堆名词绕晕。这一页不追求严谨定义，先把**每个词在说什么**讲明白，够你继续往下读就行。

## 三个圈：AI ⊃ 机器学习 ⊃ 深度学习

它们不是三个并列的东西，而是层层包含的关系：

```text
人工智能 AI（最大的圈）
└── 机器学习 ML
    └── 深度学习 DL（最小的圈）
```

| 名词 | 一句话说明 | 例子 |
| --- | --- | --- |
| 人工智能 AI | 让机器做**看起来需要人类智能**的事 | 下棋、识图、对话、自动驾驶 |
| 机器学习 ML | 不手写规则，让机器**从数据里自己总结规律** | 用一万封邮件学会分辨垃圾邮件 |
| 深度学习 DL | 机器学习的一种方法，用**多层神经网络**学规律 | 今天的大模型基本都基于它 |

::: tip 一个帮助记忆的类比
- **传统编程**：人写规则 → 机器执行（人告诉机器怎么做）
- **机器学习**：人给数据和答案 → 机器自己找规则（人告诉机器要什么）
- **深度学习**：同上，但"找规则"的方式换成了多层神经网络，能处理更复杂的东西（图片、语音、文字）
:::

## 人工智能（AI）

只要是机器完成的、过去需要人动脑子才能做的事，都可以算 AI。它不要求机器真的"思考"——计算器算得快不算 AI，但机器能看懂一张照片里有只猫，就算。

AI 里除了机器学习，还有一支是**规则/符号方法**：专家把人类的知识写成规则让机器照着做（比如早期的专家系统）。今天大家说的 AI，基本都指机器学习这条线。

## 机器学习（ML）

核心想法只有一句：**不给机器写死规则，而是给它一堆例子，让它自己总结出规则。**

按"给的例子长什么样"，机器学习分成三类：

| 类型 | 数据长什么样 | 直观理解 | 例子 |
| --- | --- | --- | --- |
| 监督学习 | 有题目也有标准答案 | 照着答案册刷题 | 给一堆标注好"猫/狗"的图片，学分类 |
| 无监督学习 | 只有题目没有答案 | 自己找规律分组 | 把用户按行为自动分成几类 |
| 强化学习 | 没有答案，只有打分 | 试错——做对了给糖 | AlphaGo 下棋、机器人学走路 |

日常接触最多的"训练一个模型"，说的通常就是监督学习。

## 深度学习（DL）

深度学习是机器学习里的一个分支，特点是用了**神经网络**——一种模仿生物神经元连接方式的数学结构，把很多层"神经元"叠在一起。

- **深** = 层数多
- 层数越多，越能表达复杂的规律，但也需要更多数据和算力
- 图像识别、语音识别、大模型，都是深度学习撑起来的

## 一定会遇到的高频名词

| 名词 | 大白话 |
| --- | --- |
| 模型 | 训练完的那个"东西"，可以看作一堆数字（参数）+ 一套计算方式。给它输入，它给输出 |
| 参数 | 模型内部那堆数字。常说的"7B 模型"就是 70 亿个参数。参数越多，通常越聪明也越贵 |
| 训练 | 用大量数据反复调整参数的过程，很费算力、很费时间 |
| 推理 | 训练好的模型拿来用（你问它一句，它答一句）。平时我们使用 AI 都是推理 |
| 数据集 | 训练用的那批材料 |
| 特征 | 喂给模型的输入里"有用的部分"。深度学习的一大好处是不用人工挑特征 |
| 过拟合 | 把训练题背得滚瓜烂熟，换个新题就不会了——学歪了 |
| Token | 模型处理文字的最小单位，不完全等于"字"或"词"。模型的收费和上下文长度都按 token 算 |
| Embedding（向量） | 把文字/图片变成一串数字，让"意思相近的东西在数字空间里也离得近"。搜索、RAG 都靠它 |
| Prompt（提示词） | 你写给模型的指令。同样的模型，prompt 写得好不好，效果差很多 |
| 上下文（Context） | 模型一次能"看到"的全部内容，包括你说的和它说的。超出长度它就会忘掉前面 |

## 生成式 AI

早期 AI 大多在做**判断**（这是不是垃圾邮件、这张图里是不是猫）。

现在火的是**生成式 AI**——让模型产出新内容：写文章、写代码、画图、做视频。第 3 页要讲的大模型（LLM），就是生成式 AI 的代表。

## 这一页记住三句话就够了

1. AI 是目标，机器学习是实现方式，深度学习是其中一种方法。
2. 机器学习 = 从数据里学规律，而不是人写规则。
3. 模型是训练出来的；训练贵、推理便宜，我们平时用的是推理。
