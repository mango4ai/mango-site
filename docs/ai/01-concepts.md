# AI 入门概念地图

刚接触 AI 时最容易被一堆名词砸晕。先记住一句话：**它们是层层包含的关系，不是三个并列的东西。**

```text
人工智能 AI  ⊃  机器学习 ML  ⊃  深度学习 DL  ⊃  大模型 LLM
```

- 凡是让机器做"看起来需要人类智能"的事，都算 AI（包括用规则写死的专家系统）。
- 机器学习是其中"从数据里学出规律"的那一大支。
- 深度学习是机器学习里"用多层神经网络"的那一小支，今天的大模型全在它里面。

## 三个词各自是什么

### 人工智能（Artificial Intelligence）

目标层面的词：**让机器完成感知、理解、推理、决策、生成这类任务**。它不规定怎么实现，所以 1950 年代手写规则的国际象棋程序和今天的 ChatGPT 都叫 AI。

### 机器学习（Machine Learning）

方法层面的词：**不写死规则，让程序从样本里自己归纳出规律**。

判断一个问题是"规则"还是"学习"，看你能不能把判断条件写清楚：

- 能写清 → 传统编程。例如"满 100 减 20"。
- 写不清但有很多例子 → 机器学习。例如"这封邮件是不是垃圾邮件"。

三种典型范式：

| 范式 | 给的是什么 | 典型任务 |
| --- | --- | --- |
| 监督学习 | 带答案的样本（输入 + 标签） | 分类、回归、翻译 |
| 无监督学习 | 只有输入，没有答案 | 聚类、降维、异常检测 |
| 强化学习 | 没有标准答案，只有奖励信号 | 下棋、对齐人类偏好（RLHF） |

### 深度学习（Deep Learning）

结构层面的词：**用很多层神经元堆叠成的网络来学习**。它最大的价值是"自动提取特征"——以前要人工设计"图片里的边缘怎么算"，现在网络自己学。

常见结构：

- 全连接网络（MLP）：最基础，表格数据用得多。
- 卷积神经网络（CNN）：吃图像，靠局部感受野抓纹理。
- 循环网络（RNN / LSTM）：吃序列，曾经是文本主流。
- Transformer：靠注意力机制并行看全序列，**现在的大模型几乎全是它**。

## 必须先认识的几个词

| 名词 | 一句话解释 |
| --- | --- |
| 模型 | 一堆参数 + 计算结构，本质上是个函数 |
| 参数 / 权重 | 模型里被训练出来的数，GPT-3 有 1750 亿个 |
| 训练 | 用大量数据反复调整参数，让预测误差变小 |
| 损失函数 | 衡量"错得多离谱"，训练就是在最小化它 |
| 梯度下降 | 沿着误差下降的方向一点点改参数 |
| 推理 | 训练好的模型拿来真正用一次 |
| 过拟合 | 背下了训练集，遇到新题就不会 |
| 泛化 | 在没见过的数据上也表现好，这才是真本事 |
| 微调 | 在已经预训练好的模型上用少量数据继续训练 |
| 生成式 AI | 输出是"新内容"（文本、图、代码）而不是一个标签 |

## 容易踩的坑

- **"AI 在数据库里查答案"**——不是。它是在参数里存下的统计规律上做概率预测，所以会一本正经地编造。
- **"参数越大越聪明"**——不完全。同样规模，数据质量和训练方法能拉开巨大差距。
- **"它理解了我在说什么"**——它擅长的是"像理解了一样接话"。这个区别在做严肃任务时要时刻记住。
