# 一、基础概念

学 AI 最容易被劝退的地方，是名词太多、而且互相套娃。这一页的目标只有一个：把最常出现的那些词，各用一句人话讲明白。看完你再看任何一篇 AI 文章，都不该再被术语卡住。

## 三个词的关系

先解决最经典的困惑：**人工智能、机器学习、深度学习，是层层包含的关系。**

- **人工智能（AI，Artificial Intelligence）**：让机器去做那些"换成人来做需要动脑子"的事——看图、说话、下棋、写代码、做计划。它是一门目标，不是某一种技术。
- **机器学习（ML，Machine Learning）**：实现 AI 的一种思路——**不把规则写死，而是给机器一堆例子，让它自己从里面总结出规律**。
- **深度学习（DL，Deep Learning）**：机器学习里的一个分支——用**很多层"人工神经元"叠起来的网络**来学规律，因为层数多，所以叫"深度"。

一句话串起来：**深度学习 ⊂ 机器学习 ⊂ 人工智能。**

### 传统编程 vs 机器学习

这是理解机器学习最快的一组对比：

| | 传统编程 | 机器学习 |
| --- | --- | --- |
| 你写什么 | 写规则 | 准备数据 |
| 机器给什么 | 按规则算出答案 | 从数据里学出规则 |
| 例子 | 写"如果邮件含'中奖'就判为垃圾邮件" | 给它 1 万封已标注的邮件，让它自己总结垃圾邮件的样子 |

关键差别在于：很多事情**人说不清规则，但能给得出例子**。"这张图里有没有猫"——你很难写出判据，但你能标出一万张图。这就是机器学习的主场。

## 模型是怎么"学"的

- **模型（Model）**：可以理解成一个**带很多可调旋钮的函数**。输入进去，输出出来；旋钮怎么拧，决定了它算得准不准。
- **参数（Parameter）/ 权重（Weight）**：就是上面那些旋钮。所谓"千亿参数大模型"，说的就是旋钮的数量有千亿个。
- **训练（Training）**：**不停地做题、对答案、拧旋钮**的过程。做错了就往正确方向微调一点，做对了就少调一点。
- **损失函数（Loss）**：一个"这次错了多少"的打分。训练的目标就是把这个分数压到最低。
- **推理（Inference）**：训练好之后拿去用——**把旋钮固定住，只管输入出新答案**。我们平时调用 AI，跑的都是推理。

### 三种学习方式

1. **监督学习**：题目**带标准答案**。给模型"图片 + 这是猫"的成对数据，它学的是输入到答案的映射。分类、识别大多属于这类。
2. **无监督学习**：题目**没有答案**，只有一堆数据，让机器自己找结构——比如把相似的客户自动聚成几类。
3. **强化学习**：没有标准答案，但有**打分**。模型自己试着做，做对了加分、做错了扣分，目标是攒够总分。AlphaGo、以及大模型的"对齐"阶段都用它。

### 数据集为什么要分三份

| 数据集 | 用来干什么 | 打个比方 |
| --- | --- | --- |
| 训练集 | 让模型在上面学 | 平时做的练习题 |
| 验证集 | 调超参、挑模型，边学边检查 | 模拟考 |
| 测试集 | 最后一次性评估，**学的时候绝不能看** | 高考 |

**过拟合（Overfitting）**：模型把练习题**背**下来了，模拟考满分，高考一塌糊涂。它记住的是噪声而不是规律。
**泛化（Generalization）**：模型在没见过的数据上依然好使——这才是我们真正想要的东西。

## 神经网络与深度学习

- **神经网络（Neural Network）**：受人脑神经元启发的一种计算结构（只是"启发"，并非真的模拟大脑）。一堆小单元按层排好，每层做一次"加权求和再套个非线性函数"，层层传下去得到结果。
- **为什么"深"重要**：层数越多，模型越能表达复杂的模式——浅层学边角线条，中层学眼睛耳朵，深层学"这是一只猫"。
- **GPU 为什么涨价**：神经网络的训练本质是海量矩阵乘法，而显卡天生就是干这个的。深度学习的爆发，硬件功劳占一半。

## 大语言模型时代的新词汇

这些词你现在躲不开，先混个脸熟：

- **Token**：模型看文本的最小单位。中文里一个 token 大约对应半个到两个汉字。**上下文窗口大小、API 计费，都是按 token 算的**。
- **Embedding（向量化 / 嵌入）**：把一段文字（或图片）**变成一串数字（向量）**，让"意思相近"变成"数字距离相近"。有了它，计算机就能比较语义相似度——搜索、推荐、RAG 都建立在这上面。
- **Transformer**：2017 年提出的网络结构，现在几乎所有大模型的底座。它的核心是**注意力机制**。
- **注意力机制（Attention）**：让模型在理解某个词时，**自己去决定该重点关注句子里的哪些其他词**。"它"指谁？注意力就是用来解决这类问题的。
- **预训练 / 微调（Pre-training / Fine-tuning）**：**预训练**是在海量通用数据上打底子，学通用能力；**微调**是在少量专门数据上再练一遍，让它更贴合某个具体场景。
- **温度（Temperature）**：控制生成的随机性。**温度低 → 稳定、保守；温度高 → 更有创意，也更容易胡说**。
- **上下文窗口（Context Window）**：模型一次能"看到"多少内容。你和它的对话、贴进去的文档，都得装进这个窗口，超了就得截断或压缩。
- **幻觉（Hallucination）**：模型**一本正经地编造事实**。它不是在查数据库，而是在预测下一个词，所以"说得顺"和"说得对"是两件事——这是目前大模型最需要警惕的缺陷。

## 小结

记住三句话就够了：

1. **AI 是目标，机器学习是方法，深度学习是方法里最火的一种。**
2. **所谓训练，就是拿数据自动拧参数；所谓推理，就是拿拧好的参数算答案。**
3. **模型不是数据库，它在预测下一个词——所以它可能说得通顺但完全错误。**
