# 2. 简史篇：AI 的三次浪潮与两次寒冬

AI 不是 2022 年才出现的。它已经反复"火了—凉了—又火了"好几轮。看懂历史，就不容易被当下的新闻带着跑。

## 时间线

| 年份 | 事件 | 为什么重要 |
| --- | --- | --- |
| 1950 | 图灵发表《计算机器与智能》，提出"模仿游戏"（图灵测试） | 在电子计算机还没普及时就问出了核心问题：机器能思考吗 |
| 1956 | **达特茅斯会议**，麦卡锡等人提出 "Artificial Intelligence" 一词 | AI 作为学科正式诞生 |
| 1957–1966 | 感知机、ELIZA 聊天程序、符号主义黄金期 | 早期乐观："二十年内机器能做人做的一切" |
| 1969 | 明斯基证明单层感知机连 XOR 都算不了 | 神经网络路线被打入冷宫 |
| 1974–1980 | **第一次 AI 寒冬** | 算力不够、承诺落空，英美大幅削减经费 |
| 1980–1987 | 专家系统（XCON）商业化成功，日本第五代计算机计划 | 知识工程火了，全球砸钱 |
| 1987–1993 | **第二次 AI 寒冬** | 专家系统维护成本高、无法泛化，专用 Lisp 机市场崩盘 |
| 1997 | 深蓝击败国际象棋世界冠军卡斯帕罗夫 | 暴力搜索 + 专用硬件的胜利，但还不是"智能" |
| 2006 | 辛顿提出深度信念网络，"深度学习"一词复兴 | 神经网络换了个名字回来 |
| 2012 | **AlexNet** 在 ImageNet 上大幅领先 | GPU + 大数据 + 深层 CNN，深度学习的引爆点 |
| 2016 | AlphaGo 击败李世石 | 强化学习 + 深度学习的公众时刻 |
| 2017 | Google 发表《Attention Is All You Need》，**Transformer** 诞生 | 今天所有大模型的地基 |
| 2018–2019 | BERT、GPT-2、"预训练 + 微调"范式确立 | NLP 从"每个任务训一个模型"变成"一个底座通吃" |
| 2020 | GPT-3（1750 亿参数），展现出少样本学习能力 | 规模带来质变，prompt 成为新的编程接口 |
| 2022 | ChatGPT 发布，两个月破亿用户 | 大模型走出实验室，成为大众产品 |
| 2023–2024 | GPT-4、开源模型井喷、多模态、长上下文、Agent 兴起 | 从"会聊天"走向"会干活" |
| 2025–2026 | 推理模型、Agent 工程化、MCP 等工具协议标准化 | 竞争焦点从模型参数转向系统能力 |

## 两次寒冬分别死在哪

- **第一次（1974–1980）：算力与复杂度双重封顶。** 当时计算机内存以 KB 计，连感知机的多层版本都训不动；更根本的是，早期符号方法只能解"玩具问题"，一碰到真实世界的模糊和噪声就崩。资助方（美国 DARPA、英国政府）发现兑现不了承诺，直接断粮。
- **第二次（1987–1993）：知识获取瓶颈。** 专家系统靠人手工把领域专家的经验写成规则，知识库一大就没人维护得起，且换个领域要从零开始。日本第五代计算机计划失败，加上专用 AI 硬件被通用工作站淘汰，泡沫破裂。

共同教训：**凡是依赖人工堆规则、又无法泛化的路线，扩展性必然撞墙。** 深度学习之所以撑起了第三波浪潮，正是因为它的"规则"是从数据里自动学出来的，加数据加算力就能继续涨。

## 第三波浪潮真正变了什么

前两次是"让机器按人的思路推理"，这一次是"让机器从数据里自己长出能力"，并且出现了三个此前没有的条件：

1. **数据**：互联网积累了海量文本、图像、代码。
2. **算力**：GPU 与分布式训练，让万亿次浮点运算的成本降到可承受。
3. **架构**：Transformer 的注意力机制，能把算力和数据高效地转成模型能力，并且可以无限堆规模。

## 一个反直觉的事实

AI 的"冬天"里并非没有进展——反向传播（1986）、LSTM（1997）、CNN（LeNet，1989）都是在低潮期打下的地基。寒冬冻死的是**过高的预期和商业泡沫**，不是技术本身。

## 还不懂的地方

- 为什么规模增长会带来"涌现"式的突然变强，学界仍在争论。
- 这一轮会不会再有寒冬？目前的共识是：即使模型能力增速放缓，工程与应用层还有很长的路要走。
