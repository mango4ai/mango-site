# 2. AI 的简要发展历程

不用背年份，看这条线就行：**AI 不是线性进步的，它经历过两次"冬天"，每次复兴都靠算力、数据、算法里某一项的突破。**

## 时间线

| 时间 | 事件 | 为什么重要 |
| --- | --- | --- |
| 1950 | 图灵提出"图灵测试" | 第一次认真讨论"机器能思考吗"，并给了个可操作的判断方式 |
| 1956 | 达特茅斯会议 | "人工智能"这个词正式诞生，领域开张 |
| 1957 | 感知机（Perceptron） | 第一个能"学习"的神经网络模型，轰动一时 |
| 1969 | 明斯基指出感知机的根本局限 | 能力被证伪，资金撤离，**第一次 AI 冬天** |
| 1980s | 专家系统兴起 | 把人类专家的规则写成知识库，商业上一度成功；但知识难维护、无法泛化，再次降温 |
| 1997 | 深蓝击败国际象棋世界冠军 | 靠暴力搜索赢的，很震撼但"不像智能" |
| 2006 | Hinton 提出深度学习的有效训练方法 | 神经网络改名"深度学习"重新出发 |
| 2012 | AlexNet 拿下 ImageNet 图像识别冠军 | **转折点**：GPU + 大数据 + 深层网络，错误率断崖式下降，深度学习一夜爆红 |
| 2016 | AlphaGo 击败李世石 | 强化学习 + 深度学习出圈，公众认知被刷新 |
| 2017 | Google 发表《Attention Is All You Need》，提出 Transformer | **今天所有大模型的地基** |
| 2018–2020 | BERT、GPT-2/GPT-3 相继出现 | 预训练范式确立：先海量预训练，再微调/提示。模型开始"变大" |
| 2022 | ChatGPT 发布 | AI 第一次变成人人可用的产品，两个月破亿用户 |
| 2023–2024 | 开源模型、多模态、长上下文爆发 | 模型不再只有一家能做，成本快速下降 |
| 2025 | 推理模型、Agent 成为主战场 | 比拼从"答得像人"转向"能不能真的把事办完" |

## 三次关键转折

### 第一次：从"人写规则"到"机器学规律"

早期思路是让人类专家把知识写成规则（专家系统）。这条路撞上了天花板：现实世界的知识根本写不完，换个领域就得重来。

机器学习的思路反了过来——不写规则，给数据让机器自己学。思路上是对的，但当时算力和数据都不够，所以只能做小事。

### 第二次：深度学习 + GPU（2012）

同样是"从数据里学"，为什么 2012 年突然成了？三个条件同时到位：

- **算力**：GPU 让训练深层网络变得可行
- **数据**：互联网积累了海量标注数据（ImageNet 是代表）
- **算法**：更深的网络结构 + 更有效的训练技巧

::: tip 记住这个公式
AI 的每一次跨越，基本都来自 **算力 × 数据 × 算法** 三者中某一项的量级突破，而不是单点小优化。
:::

### 第三次：Transformer + 预训练（2017 起）

Transformer 解决了"长文本里前后文难以关联"的问题，而且**极其适合并行计算**——这意味着可以把模型和数据同时放大到以前不敢想规模。

于是出现了新玩法：先用海量通用文本做一次"预训练"（等于让模型读了整个互联网），之后不用重新训练，靠提示词就能干各种活。这就是**大模型**的由来。

## 两次"冬天"的共同教训

| 冬天 | 发生了什么 | 教训 |
| --- | --- | --- |
| 1970s | 感知机能力被证明有限，承诺落空 | 过度承诺 + 方法本身有天花板 |
| 1980s 末 | 专家系统维护成本失控 | 能演示 ≠ 能规模化 |

规律很朴素：**当一个方法的能力被高估、成本被低估时，泡沫就会破。** 这一轮大模型热潮同样值得用这个角度看。

## 一条主线总结

```text
规则驱动（专家系统）
      ↓ 写不完规则
数据驱动（机器学习）
      ↓ 算力和数据不够
深度学习（GPU + 大数据）
      ↓ 需要更强的"理解关联"能力
Transformer + 预训练 = 大模型
      ↓ 从"会说"到"会做"
Agent（能调用工具把事办完）
```
