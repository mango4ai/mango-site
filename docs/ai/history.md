# 二、AI 的简要发展历程

AI 不是 2022 年突然冒出来的。它已经七十多岁了，中间经历过**两次寒冬**——吹得太大、兑现不了、 funding 断掉、大家闭嘴十年。看懂这条曲线，你就不会在今天这波热潮里失去判断力。

## 时间线

| 年代 | 发生了什么 | 为什么重要 |
| --- | --- | --- |
| 1950 | 图灵发表《计算机器与智能》，提出**图灵测试** | 在电子计算机还没普及的年代，先给出了"机器能不能思考"的可操作判据 |
| 1956 | **达特茅斯会议**，"人工智能"这个词正式诞生 | 一群人立了个 flag：暑假两个月搞定智能问题。显然没搞定，但学科就此成立 |
| 1957–1969 | **感知机**出现，能学简单的线性分类 | 第一次让"机器可以从数据里学"有了具体实现 |
| 1969 | 被证明连"异或（XOR）"这种简单问题都解不了 | 期望落空 + 算力不足 → **第一次寒冬** |
| 1980s | **专家系统**流行：把人类专家的规则写成知识库 | 第一次真正商业落地，但规则写不完、维护不动，成本高得离谱 |
| 1986 | **反向传播算法**普及，多层网络终于训得动 | 今天所有神经网络训练的理论基石 |
| 1990s | 专家系统泡沫破裂 → **第二次寒冬** | 统计学习（SVM 等）接棒，AI 这个词一度没人爱提 |
| 1997 | IBM 深蓝击败国际象棋世界冠军 | 靠的是暴力搜索 + 专用硬件，不是"学习"，但震撼了公众 |
| 2012 | **AlexNet** 在图像识别大赛上碾压式夺冠 | 深度学习爆发的起点：GPU + 大数据 + 深层网络，三件事同时到位 |
| 2016 | AlphaGo 战胜李世石 | 强化学习 + 深度学习的公开亮相，AI 第一次"下出了人类没见过的棋" |
| 2017 | Google 发表论文《Attention Is All You Need》，提出 **Transformer** | 今天所有大模型的共同底座，重要性怎么强调都不过分 |
| 2018–2021 | BERT、GPT 系列、扩散模型陆续出现 | 预训练范式成型：先在海量数据上打底子，再迁移到具体任务 |
| 2022 年 11 月 | **ChatGPT 发布**，两个月破亿用户 | 大模型第一次变成人人可用的产品，而不只是论文和 API |
| 2023–至今 | 多模态、长上下文、推理模型、**Agent** 与工具调用 | 竞争焦点从"模型有多大"转向"模型能不能真的把活干完" |

## 三次范式转变

把七十年压缩成三次思路切换，比记年份有用得多：

1. **规则时代（1950s–1980s）**：人把知识写成规则教给机器。
   → 死穴：真实世界的规则写不完，写完也维护不动。
2. **学习时代（1980s–2017）**：人给数据，机器自己总结规律。
   → 死穴：每个任务都要单独标注数据、单独训练一个模型，泛化能力差。
3. **基础模型时代（2018–至今）**：**先在一个超大模型上吸收通用能力，再快速适配到无数具体任务**。
   → 这才是"大模型"真正的革命性：不是更聪明一点，而是**一个模型干掉一万个专用模型**。

## 这波热潮为什么不一样

历史上每次 AI 热潮都是"能力上去了，但落地场景没跟上"。这一轮的差别在三点：

- **通用性**：以前一个模型只能干一件事（下棋、识图），现在同一个模型能写代码、改文案、做分析、调工具。
- **交互门槛归零**：不需要会编程，会打字就能用。这直接把用户从几万人变成几亿人。
- **能力可以外挂**：模型能调工具、查资料、执行代码——它不只是一个"会说"的东西，开始变成"会做"的东西（这就是后面 [Agent](/ai/agent) 那一页要讲的）。

## 一句提醒

读历史最大的收获是：**AI 领域每次"再过十年就能通用智能"的预言，都没有如期兑现**。所以面对今天的进展，值得兴奋，但不必恐慌，也别轻信任何时间点承诺。
